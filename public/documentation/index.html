Welcome to the NEXAI AI SaaS & Technology Template documentation. This comprehensive React template is built with Vite 8, React 19, Tailwind v4, and modern web technologies to help you build powerful, responsive SaaS platforms and technology websites. Following industry best practices, NEXAI combines beautiful dark cyber design with professional performance functionality to accelerate your development process.

4. Installation Guide

Get the template set up and running on your local machine with these simple steps:

1
Install Dependencies
Run npm install to download all required packages into node_modules:
terminal 
npm install
2
Run Dev Server
Start the local development server with instant Hot Module Replacement (HMR):
terminal 
npm run dev

Open http://localhost:5173 in your browser.

3
Build Production
Compile and optimize your project for live production deployment:
terminal 
npm run build

Outputs optimized production files into the dist/ folder.

4
Preview Build
Test your compiled production build locally before uploading:
terminal 
npm run preview

Verifies production behavior and asset caching locally.

2. Updating Colors & Tailwind CSS v4 Theme

NEXAI is engineered with Tailwind CSS v4 using the native @theme directive in src/index.css. No complicated config files are needed:

  • Open src/index.css.
  • Modify or extend typography and custom color tokens inside the @theme block:
src/index.css 
/* In src/index.css */
@import "tailwindcss";

@theme inline {
  --font-sans: 'Plus Jakarta Sans', system-ui, sans-serif;
  
  /* Add custom brand color tokens */
  --color-primary: #06b6d4;
  --color-primary-hover: #0891b2;
}

Vite provides instant Hot Module Replacement (HMR), so any CSS or component modifications will immediately reflect in your browser.

4. Dark & Light Mode Implementation (React Context)

NEXAI includes a complete, production-grade Dark and Light mode powered by React 19 Context and Tailwind CSS v4:

  • Global ThemeProvider: Wrapped at the application root in src/main.jsx via src/context/ThemeContext.jsx.
  • Custom Hook: Access const { theme, toggleTheme, setTheme } = useTheme(); in any component.
  • Persistence & OS Detection: Automatically loads user preference from localStorage.getItem('nexai-theme') or falls back to system window.matchMedia('(prefers-color-scheme: dark)').
  • DOM Synchronization: Toggles the dark class and color-scheme attribute directly on the root <html> element.
Example: Using useTheme in a Component 
import { useTheme } from '@/context/ThemeContext';
import { Sun, Moon } from 'lucide-react';

export const ThemeToggle = () => {
  const { theme, toggleTheme } = useTheme();

  return (
    <button 
      onClick={toggleTheme}
      aria-label="Toggle theme"
      className="p-2 rounded-xl border border-slate-200 dark:border-white/10 bg-white dark:bg-white/5"
    >
      {theme === 'dark' ? <Sun className="w-4 h-4 text-amber-400" /> : <Moon className="w-4 h-4 text-cyan-600" />}
    </button>
  );
};

Located in src/context/ThemeContext.jsx. You can customize the default starting theme, the local storage key, or connect an external user profile preference:

// Inside src/context/ThemeContext.jsx

export const useTheme = () => useContext(ThemeContext);
5. Live Contact Form Webhook

In src/pages/ContactPage.jsx, form submissions can be directed to Formspree, Basin, or your custom API endpoint simply by specifying VITE_CONTACT_FORM_ENDPOINT in a .env file.

6. Live Settings Customizer & Direction Context (LTR / RTL)

Managed via src/context/SettingsContext.jsx and rendered through src/components/layout/SettingsSidebar.jsx. The floating drawer customizer lets users switch layout direction (LTR / RTL), toggle Dark / Light mode, and preview 6 dynamic brand accent colors (Cyan, Indigo, Emerald, Violet, Rose, Amber) in real time:

Consuming useSettings in Components 
import { useSettings } from '@/context/SettingsContext';

export const SettingsButton = () => {
  const { direction, setDirection, accentColor, setAccentColor, toggleSettings, resetDefaults } = useSettings();

  return (
    <div className="flex items-center gap-2">
      <button onClick={toggleSettings}>Open Customizer</button>
      <button onClick={() => setDirection(direction === 'ltr' ? 'rtl' : 'ltr')}>
        Direction: {direction.toUpperCase()}
      </button>
    </div>
  );
};

8. Color & Font Customization

Color Customization & Dark/Light Mode

NEXAI uses Tailwind CSS v4 styling with native dark: variant support. Both dark cyber and crisp light palettes are configured in src/index.css.

Tailwind CSS v4 Directives
src/index.css 
/* In src/index.css */
@import "tailwindcss";

/* Enables class-based dark mode on <html class="dark"> */
@custom-variant dark (&:where(.dark, .dark *));

@theme inline {
  --font-sans: 'Plus Jakarta Sans', system-ui, sans-serif;

  /* Add custom brand colors */
  --color-primary: #06b6d4;
  --color-primary-hover: #0891b2;
  --color-secondary: #6366f1;
}

To style any component for both light and dark modes, simply apply standard Tailwind utility classes for light mode and prefix with dark: for dark mode:

Dual-Theme Component Styling Example 
<div className="bg-slate-50 dark:bg-black text-slate-900 dark:text-slate-100 border border-slate-200 dark:border-white/10">
  <h3 className="text-slate-900 dark:text-white">Cyber Threat Radar</h3>
  <p className="text-slate-600 dark:text-slate-400">Autonomous eBPF telemetry active.</p>
</div>

You can also use any of Tailwind CSS's built-in color palettes (cyan, indigo, violet, slate, etc.) anywhere in component className props.

Dynamic Brand Accent Colors (Live Customizer)

NEXAI supports instant brand accent switching powered by SettingsContext.jsx. Six preset cyber palettes (Cyan #06b6d4, Indigo #6366f1, Emerald #10b981, Violet #8b5cf6, Rose #f43f5e, Amber #f59e0b) are selectable in the Live Customizer drawer, updating CSS variables (--color-primary, --color-primary-hover, --brand-accent) on the document root without reloading.
