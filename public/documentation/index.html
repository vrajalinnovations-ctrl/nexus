Quick Start in 1 Minute

Get the project up and running locally with just two simple terminal commands:

1
Install Dependencies
Installs all active packages declared in package.json:
terminal 
npm install
2
Start Development Server
Launches Vite hot-module reload in development mode:
terminal 
npm run dev
3
Build for Production
Compiles minified production bundle into the dist/ folder:
terminal 
npm run build

Backend & Webhook Integration Guide

AEGIX is designed as a modular, frontend-first React 19 template. Follow these quick guides to connect live endpoints:

1. Live Contact Form (Formspree / Webhooks)
Add your live submission endpoint in a .env file in your project root:
.env 
VITE_CONTACT_FORM_ENDPOINT="https://formspree.io/f/your_form_id"

When provided, ContactPage.jsx automatically sends real JSON payloads with name, email, organization, topic, and message.

2. Authentication Suite (Supabase / Clerk / Firebase)
All authentication views in src/auth/ contain isolated submit handlers. Simply replace the demo state with your SDK client:
src/auth/SignInPage.jsx 
// Example Supabase Client
const { data, error } = await supabase.auth.signInWithPassword({
  email,
  password
});

Frequently Asked Questions

How do I replace the logo with my own company branding?
Simply replace src/assets/logo.png and public/logo.png with your company logo PNG file. All navigation bars, footers, error pages, and authentication screens automatically import and scale this asset.
How can I modify pricing tiers or FAQ questions?
Open src/mock/pricing.json. You can easily edit tier names, prices, monthly/annual discounts, feature checklist items, and accordion questions without touching any JSX code.
How do I connect real backend authentication APIs?
In src/auth/SignInPage.jsx, SignUpPage.jsx, and VerifyPage.jsx, replace the simulated setTimeout handlers inside handleSubmit with your actual fetch() or axios calls to your authentication endpoints (e.g. Supabase, Firebase, or custom REST APIs).
Why is there only one Google Font loaded?
Loading multiple Google Fonts causes render-blocking network delays and layout shifts. Standardizing on Plus Jakarta Sans ensures instantaneous page loads, 100/100 Lighthouse performance, and pristine typographic consistency.
